# 《雾乡如昨》Demo 旧矿道与战斗垂直切片

## 文档地位

本文件是阶段 10E 对“把矿洞、战斗加入当前 Demo”的权威玩法规格。地图拓扑与 `docs/DEMO_MAP_FLOW.md` 共同生效，存档和历法与 `docs/DEMO_SAVE_AND_CALENDAR.md` 共同生效。发生冲突时，本文件决定矿洞、采矿和战斗行为；叙事保密边界仍以 `docs/NARRATIVE_BIBLE.md` 为准。

本阶段只冻结范围、规则、数据边界和后续验收，不创建 Cocos 场景、脚本、`.meta`、美术、音乐或音效资源。

## 体验目标

矿洞切片要证明“田园日常之外可以偶尔外出挖矿打怪”，但不能变成另一套完整游戏。一次首次体验应形成以下闭环：

1. 玩家完成第一日基础农务后，可在故乡主区域发现并进入旧矿道；
2. 使用快捷栏中的锄镐采集一类矿脉，矿石进入真实背包；
3. 使用学院练习杖击败一场固定基础敌人遭遇；
4. 玩家可以主动离开，或在生命耗尽时安全撤离；
5. 当日结果可保存和读取，睡觉后矿脉与遭遇按新日规则重置；
6. 是否进入矿洞不影响关系片段、第一处异常入口或 Demo 里程碑。

## 第四张地图：`old_mine`

### 职责

- 承载单层固定矿道、采矿教学与一场基础战斗；
- 给完整产品的探索、采集和战斗方向提供代表性样片；
- 使用日常世界的普通魔法生态，不提前泄露战争残响或愿境真相；
- 可被玩家长期忽略，不阻塞睡觉、耕种、关系或边界调查。

### 初始灰盒预算

| 项目 | 决定 |
| --- | --- |
| 地图 ID | `old_mine` |
| 玩家可见名称 | 本地化键 `map.old_mine.name`，正文暂称“旧矿道” |
| 初始尺寸 | `32×24` 个 `32×32` 瓦片，即 `1024×768` 世界像素 |
| 楼层 | 一层手工布局，不随机生成 |
| 入口 | `hometown_main/main_old_mine_path` → `old_mine/mine_entry` |
| 出口 | `old_mine/mine_exit` → `hometown_main/main_old_mine_return` |
| 安全撤离点 | `mine_safe_return`，位于入口内侧且不与敌人或矿脉重叠 |
| 采矿区 | `mine_ore_patch`，包含少量稳定 ID 矿脉 |
| 战斗区 | `mine_combat_room`，包含一场稳定 ID 遭遇 |

地图不连接 `boundary_pass`，不能把矿洞深处伪装成第二处结界异常。入口在完成 `daily.farmingIntroCompleted` 后开放；它不要求关系事件、第二天或异常状态。

### 灰盒动线

```text
hometown_main
      |
      v
+-------------------------------+
| mine_entry / mine_safe_return |
|            |                  |
|       采矿支路 O              |
|            |                  |
|       固定遭遇 C              |
|            |                  |
|        短回环 -> mine_exit    |
+-------------------------------+
```

首次进入必须能在不战斗的情况下退出。战斗区不得堵住唯一出口；生命归零和地图加载失败都能回到命名安全点。

## 采矿规则

### 工具与输入

- 起始物品增加锄镐 `tool_pickaxe`；正式玩家可见名称由本地化数据决定。
- 玩家选中锄镐后，在 `gameplay` 输入上下文中按统一 `primaryAction`，只尝试命中面对方向相邻一格的矿脉。
- 选中其他物品时不会采矿；矿洞地面也不能被锄地、播种或浇水。
- PC 与微信触控只提供同一语义动作；玩法代码不得读取空格键、屏幕按钮节点或 `wx`。

### 矿脉与产物

- 当前切片只提供一类矿脉 `ore_vein_common`，每个实例拥有稳定 `nodeId`。
- 初始平衡值为 3 次有效锄镐命中后破碎；数值进入 JSON，不硬编码在 Cocos 组件。
- 破碎后尝试把一种原创矿石 `mist_iron_ore` 加入真实背包。
- 背包没有容量时，最后一次命中不提交破碎状态，并显示“背包已满”；不能先删矿脉再丢奖励。
- 同一 `nodeId` 在同一 `worldDay` 只能成功产出一次，睡觉进入下一天后重置。
- 当前 Demo 不实现矿石出售、锻造、装备强化、采矿技能、体力消耗或随机稀有掉落。

采矿事务必须原子提交：验证目标、验证工具、计算耐久、验证背包容量、写入矿脉状态和背包产物要么全部成功，要么保持旧状态。

## 战斗规则

### 玩家攻击

- 起始物品增加 `academy_practice_wand`，表现为学院停课前保留的练习法器，不承诺正式外观。
- 选中练习杖后，`primaryAction` 发出沿当前朝向前进、最远 3 格的基础魔法脉冲。
- 初始平衡值：每次命中造成 1 点伤害，攻击冷却 0.35 秒；表现时长不得成为权威判定来源。
- 攻击期间不创建新的平台输入模式；暂停、对白、模态和地图切换上下文必须抑制攻击。

### 基础敌人

- 当前切片只有一种敌人定义 `enemy_cave_mote`，玩家可见名称和正式造型留给独立资源任务。
- 单场固定遭遇最多 3 个实例，首版目标为 2 个；每个实例属于稳定 `encounterId`。
- 初始平衡值：3 点生命；在有限感知范围内追逐，接触玩家时造成伤害；脱离战斗区后回到固定出生锚点。
- 敌人使用地图碰撞和受控移动，不穿墙，不要求导航网格、群体战术、远程攻击或复杂状态机。
- 当前敌人不掉落物品；采矿已经提供背包奖励，避免在没有经济系统时制造两套掉落事务。
- `enemy_cave_mote` 是普通魔法生态威胁，不是死者灵魂、重构村民、战争残响或真相线 Boss。

### 生命、受伤与安全撤离

| 规则 | 初始值/行为 |
| --- | --- |
| 玩家最大生命 | 5 点 |
| 接触伤害 | 1 点 |
| 受伤无敌 | 0.75 秒 |
| 生命显示 | 矿洞内或生命未满时显示 5 格紧凑生命 HUD |
| 归零结果 | 原子安全撤离到 `mine_safe_return` |
| 日期 | 不推进 |
| 背包 | 不丢失、不扣除 |
| 当日矿洞结果 | 已采空矿脉和已完成遭遇保持，不重复产出 |
| 恢复 | 撤离完成后回满生命；睡觉也回满生命 |

生命为 0 只允许存在于撤离事务内部，稳定存档中的生命必须为 `1～5`。前后台切换、暂停、场景卸载和读档必须清理攻击、击退、无敌计时与按键门闩，不能在恢复后自动继续攻击或再次扣血。

## 当日状态与存档

SaveData v2 增加明确字段，而不是无类型通用字典：

```ts
interface PlayerVitalsState {
  readonly health: number;
  readonly maxHealth: 5;
}

interface MineRunState {
  readonly mapId: 'old_mine';
  readonly worldDay: number;
  readonly brokenNodeIds: readonly string[];
  readonly defeatedEncounterIds: readonly string[];
}
```

规则：

- 新档与 v1 迁移档默认满生命，矿洞状态为空；
- 保存当前地图为 `old_mine` 时同时保存玩家位置、朝向、生命和当前日矿洞状态；
- 读取时若 `mineRun.worldDay !== save.worldDay`，拒绝损坏载荷；正常跨天会在保存前把矿洞状态重置为新日空状态；
- `brokenNodeIds` 和 `defeatedEncounterIds` 必须引用当前矿洞目录中的稳定 ID，重复 ID 非法；
- 矿脉剩余命中次数、敌人当前生命、临时位置、投射物、冷却和无敌计时不保存；读取后未完成对象回到定义的初始状态；
- 安全撤离完成前不能写入稳定自动保存；若恢复计划发现非法位置，回退到 `mine_safe_return`。

阶段 12B 在 SaveData v2 首次落地时建立字段、默认值、v1 迁移和校验；阶段 15A 再接入真实采矿/战斗运行时状态。

## UI、可访问性与平台规则

- 快捷栏继续显示 8 格；锄镐和练习杖使用现有选择语义，不新增独立武器栏。
- HUD 显示选中工具、生命、命中/受伤反馈和“背包已满/工具不符/安全撤离”本地化提示。
- 微信右侧主动作按钮根据选中物品显示采矿或攻击图标，但发送的仍是 `primaryAction`。
- 受伤反馈必须同时包含形状/闪烁或轻微位移与可选音效，不能只靠红色或屏幕震动。
- 屏幕震动、粒子、命中停顿和闪烁强度都应有画质/可访问性开关；关闭后不改变判定。
- 战斗时暂停必须冻结权威模拟；应用进入后台时释放全部输入并在稳定状态下按平台策略保存。

## 明确不做

- 随机楼层、无限矿洞、电梯、矿层进度或每日地图种子；
- 第二类矿脉、稀有矿、宝箱、炸弹或采矿体力；
- 第二种敌人、精英怪、Boss、战争残响战斗或秘境；
- 装备栏、护甲、武器强化、属性成长、技能树或等级；
- 商店、出售、价格、锻造、制作和完整战利品经济；
- 复杂导航、敌人远程攻击、异常状态、元素克制或多人战斗；
- 把矿洞作为第一处结界异常或不可逆调查的前置条件。

## 实现顺序

1. 阶段 11：第四张地图灰盒、入口/出口、安全点、碰撞、相机与性能预算；不实现战斗。
2. 阶段 12A～12C：语义输入、SaveData v2 字段、HUD 与触控布局预留。
3. 阶段 15A：先纯规则采矿事务与生命/伤害/撤离，再 Tiled/Cocos adapter，最后固定遭遇与存读档。
4. 阶段 15A 灰盒验收后：另开旧矿道视觉任务和战斗/采集音频任务。
5. 阶段 16：导入通过验收的正式资源并调整节奏；不得借资源制作扩大玩法。
6. 阶段 17～20：微信触控/真机、Windows 和 Steam 构建回归完整矿洞闭环。

## 验收清单

- 玩家可从 `hometown_main` 双向进入/离开 `old_mine`，失败加载有命名安全回退。
- 未完成关系或异常内容也能进入矿洞；不进入矿洞不阻塞其他 Demo 内容。
- 锄镐只采面对格矿脉；3 次有效命中后矿石原子进入背包。
- 背包满时矿脉不消失，同一矿脉同日不重复产出。
- 练习杖只在选中时攻击；固定敌人可受伤、被击败且不穿墙。
- 接触伤害、无敌窗口和生命 HUD 可读；生命归零安全撤离、不跨天、不丢物。
- 保存并重读后生命、已采矿脉和已完成遭遇一致；跨天后矿洞当日状态重置。
- PC 键盘与微信触控共享语义输入，暂停/对白/后台不会残留攻击。
- 640×360 和另一横屏比例可读；`wechat-low` 关闭粒子、震动和高成本效果后仍能完成战斗。
- 没有新增战争残响、亡灵、愿境或核心真相泄露。
