# Art Guide

## 目标

建立原创、可读、适合移动端和 PC 的 2D 像素视觉，同时让所有资源具备清晰来源。

## 已确认的视觉方向

- 东方幻想药圃：山雾、木构、石径、药草和柔和水色。
- 轮廓清晰，角色、可交互地块和背景有明确层级。
- 使用有限色板和统一光照方向。
- 不模仿或描摹任何具体商业游戏的角色比例、建筑、UI、地图或图块。

## MVP 资源策略

- 玩法验证阶段优先使用原创几何占位图和简单色块。
- 没有来源记录的图片、字体、音频不得导入项目。
- AI 生成资源若使用，必须记录生成工具、日期、提示词摘要、人工修改和适用条款，并进行相似性审查。
- 购买或开源资源必须保留许可证、购买凭证和作者信息。
- 项目运行时素材的逐项来源记录维护在 `docs/ASSET_SOURCES.md`。

## Pixel Rules

已确认：

- 基础瓦片为 32×32 像素。
- 逻辑设计分辨率为横屏 640×360。
- 美术阶段先使用项目内原创占位资源。

以下参数在地图阶段通过编辑器原型确定后锁定：

- 角色逻辑脚点和碰撞体尺寸。
- Pixels Per Unit / 纹理像素映射策略。
- 点过滤、图集边缘扩展、间距和压缩设置。
- UI 是否使用像素字体或高分辨率矢量/位图字体。

必须在目标分辨率检查：

- 非整数缩放导致的抖动和模糊。
- TMX 图块接缝与纹理渗色。
- 相机移动时的像素稳定性。
- 手机安全区和触控按钮可读性。

Cocos 3.8.5 及之后的 TiledMap 图集边缘处理有特别说明，地图阶段按所选编辑器版本复核：<https://docs.cocos.com/creator/3.8/manual/en/asset/tiledmap.html>

## Naming and Layout

建议命名：

```text
textures/
  characters/player/
  crops/mistleaf/
  environment/farm/
  ui/
animations/
audio/
  music/
  sfx/
```

- 文件名使用小写英文 `snake_case`。
- 生长阶段使用明确序号，例如 `mistleaf_stage_00.png`。
- 源文件与导出文件分离；大型源文件不自动进入运行时包。

## UI

- 先满足触控点击面积、对比度和安全区，再装饰。
- 微信端和 PC 端共享信息架构，可有不同输入提示。
- 不复制其他游戏的工具栏布局、图标造型或像素字体。

## Audio

- MVP 可完全无音乐，仅保留原创或授权的必要反馈音。
- 音频必须支持静音和前后台暂停。
- 不使用任何商业游戏解包或重新录制的音频。

## Review Checklist

- 来源、作者、许可证和修改记录齐全。
- 与参考商业作品没有近似角色、建筑、图块、UI 或图标。
- 导入设置与像素规范一致。
- 在微信真机与 Windows 构建上检查清晰度、内存和加载。
