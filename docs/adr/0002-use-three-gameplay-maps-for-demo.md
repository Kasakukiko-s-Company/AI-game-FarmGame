# ADR-0002：Demo 使用三张职责分离的玩法地图

## 状态

已取代；由 ADR-0006 取代

## 历史决策

阶段 10B 曾决定 Demo 使用 `home_interior`、`hometown_main` 和 `boundary_pass` 三张可独立加载的玩法地图，并将农场与村庄合并在日常主区域。该方案比继续扩张单张技术测试地图更能分离开场、长期生活和结界异常，又比拆分农场、村庄、道路等更多地图更容易控制灰盒、内容、美术和移动端内存成本；标题与存档界面属于应用 UI，不计入三张地图。

阶段 10E 期间，用户明确要求把矿洞与战斗加入当前 Demo。新增 `old_mine` 的范围、边界和迁移后果由 `docs/adr/0006-add-fixed-mine-and-combat-slice.md` 记录；原有三张地图的职责与连接仍然有效，只是不再构成地图数量上限。
