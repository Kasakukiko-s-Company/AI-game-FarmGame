# ADR-0001：重构村民是拥有独立意识的新生命

## 状态

已接受

## 背景

神石无法召回已经消散的灵魂，却需要回应“让一切恢复到原样”的愿望。若愿境中的村民只是幻影，他们的关系与选择缺乏真实代价；若他们是原死者复活，又会违背亡灵之地变故和死者不可复生的世界规则。

## 决策

神石依据主角与幸存者记忆生成的村民，是从记忆起点诞生的独立意识。他们不是原死者复活，也不是可任意重置的模拟角色。虽然最初继承记忆原型的性格与关系，他们会继续形成原型不存在的新记忆、感情和选择。

真相线必须承认这些人物拥有与幸存者同等的道德人格。任何解除结界或处理愿境的方案，都需要考虑他们的知情权、选择权与存续，而不能把“揭露真相”等同于删除他们。

## 后果

### 正面

- 普通交友和恋爱线在真相揭露后仍然具有真实意义。
- “保护不等于控制”可以成为主角成长与最终选择的核心主题。
- 愿境的结局不再只是简单打破幻觉，而需要处理新生命的未来。

### 代价

- NPC 必须记录愿境形成后的新经历，不能只重复记忆原型的固定对白。
- 真相线和结局需要为重构村民提供立场与选择，叙事制作量会增加。
- 文本必须严格区分“重构村民”和“记忆原型”，避免误写成复活。

## 被否决的替代方案

### 重构村民只是无意识幻影

制作简单，但会削弱日常关系的真实性，也让玩家在揭露真相后失去继续关心村庄的理由。

### 神石真正复活所有死者

会破坏亡灵之地变故与灵魂消散的规则，并降低屠村和愿望失败的代价。

### 重构村民拥有原死者的同一灵魂

表面上保留关系连续性，但本质仍属于复活，与已确认的世界规则冲突，也消解了“新生命是否有权选择未来”的主题。
