# MVP

> 本文记录“技术 MVP”的历史目标与实际完成情况，不再定义当前产品范围。当前里程碑以[《雾乡如昨》游戏 Demo](DEMO_SCOPE.md)为准。下文明确区分“已完成”和“延期到平台交付”，不能把原始验收目标误记为当前事实。

## 目标

证明一条跨平台、可保存、可重新加载的最小种植闭环真实可运行。MVP 不是内容完整的农场游戏。

## 玩家能够完成的完整流程

1. 进入游戏。
2. 创建新存档或加载已有存档。
3. 在农场中四方向移动。
4. 使用锄头开垦允许耕作的土地。
5. 选择种子并播种。
6. 使用水壶浇水。
7. 在睡觉点结束当天。
8. 作物按配置经过若干个有效生长日成熟。
9. 玩家收获成熟作物，物品进入背包。
10. 保存并退出。
11. 重新进入后，日期、位置、背包、地块和作物状态仍然存在。

## 地图

- 一张使用 32×32 像素瓦片的 30×30 农场/药圃。
- 一间不可进入的小屋，仅提供外观和睡觉交互点。
- 一块 10×10 可耕作区域。
- 明确的不可通行边界与少量碰撞物。

## 玩家与输入

- 四方向角色移动与最后朝向。
- PC 支持 WASD 和方向键。
- 已完成 PC 键盘输入和平台无关语义输入接口。
- 微信触控移动和动作入口属于原始目标，但尚未实现；安排在 Demo 的应用外壳原型与微信触控里程碑。
- 碰撞和摄像机跟随。

## 物品

- 锄头。
- 水壶。
- 一种原创种子。
- 一种对应的成熟收获物。

## 系统

- 瓦片交互与可耕作性。
- 土地状态：普通、已耕作、当日已浇水。
- 作物状态：种类、阶段、生长进度、种植日。
- 简单固定容量背包与快捷栏。
- 游戏日与睡觉结算。
- 一个自动存档槽的本地保存与读取。
- Desktop/WeChat 平台身份、接口与 composition 护栏。
- 实际微信 adapter、Windows 本地文件 adapter 和运行时 composition/bootstrap 尚未完成，不能标记为技术 MVP 已交付能力。

## 明确不做

- 商店、出售、货币、升级和加工。
- NPC、关系、剧情、对白和任务。
- 战斗、矿洞、钓鱼、节日和多人。
- 天气、四季、体力、复杂动画和完整音频。
- 支付、广告、排行榜、登录和云存档。
- 可进入房屋、多地图传送和完整设置菜单。

## 已完成的功能验收

- 从播种到成熟收获的闭环可重复完成。
- 只有允许耕作且空闲的瓦片能被开垦和播种。
- 浇水与成长规则在跨天时只结算一次。
- 当天未浇水的作物停止成长，但不会枯死或倒退。
- PC 键盘可以完整操作。
- 保存后重新启动能恢复全部 MVP 权威状态。
- 损坏或版本不支持的存档不会导致静默丢档。
- 没有使用商业游戏或来源不明的素材。

## 延期到平台交付的原始功能验收

- 微信触控在真机完成完整流程。
- 微信前后台切换释放输入并安全保存。
- Windows 原生构建在未安装编辑器的环境完成相同闭环。

## 已完成的技术验收

- 核心玩法不直接访问 `wx`、`window` 或 `localStorage`。
- 内容数据来自经过校验的 JSON，而不是散落在业务代码中。
- 农田和作物以瓦片坐标保存。
- 关键纯逻辑具有自动化测试：坐标转换、成长、背包和存档 round-trip。
- Cocos Creator 3.8.8 编辑器和浏览器预览没有已知未解释的项目错误。

## 延期到平台交付的原始技术验收

- 微信开发者工具和真机没有未解释错误。
- Steam/Windows 构建在没有编辑器运行的环境中可启动。

## 退出技术 MVP 的门槛

核心玩法、背包、快捷栏和浏览器本地存档闭环已经完成。微信真机与 Windows 原生验证仍属于后续平台交付工作。

当前允许进入 Demo 内容制作，但每个阶段仍以 `docs/DEMO_SCOPE.md` 为上限。完整恋爱、通用 NPC 日程、矿洞、战斗、经济、倒叙真相章和大型内容系统都必须先单独锁定范围，不能把完整游戏愿景直接视为当前实现授权。
