# 《雾乡如昨》美术资源需求清单

## 使用方式

本清单只锁定首批视觉验证包。状态使用：

- `[ ]` 未开始
- `[~]` 制作或评审中
- `[x]` 已通过运行时验收

任何资源只有在源文件、导出文件、来源登记和 Cocos 实机/预览验证都完成后才能标记 `[x]`。

状态：`[ ]`

| 项目 | 规格 |
| --- | --- |
| 角色数量 | 1 |
| 当前形态 | 男性主角；用于第一批视觉验证 |

## 环境状态验证

以下不是四套完整地图资产，而是同一小场景的效果组合：

### AVP-FX-001 白天

状态：`[ ]`

- 基础色板，无强制全屏色偏。
- 角色、小屋、树和作物的左上受光一致。

### AVP-FX-002 黄昏

状态：`[ ]`

- 暖色覆盖层。
- 不修改玩法层或复制地表图。

### AVP-FX-003 夜晚

状态：`[ ]`

- 蓝紫覆盖层。
- 小屋窗户或一处局部柔光 Sprite。
- 关闭柔光后仍能辨认路径、角色和交互物。

### AVP-FX-004 下雨

状态：`[ ]`

- 轻量雨滴粒子和冷色/低饱和调整。
- `wechat-low` 首轮粒子预算不超过 64 个屏幕内实例。
- 关闭粒子后仍通过 UI 或音频表达天气。

### AVP-FX-005 第一处异常最小状态

状态：`[ ]`，必须先由阶段 10D 锁定异常节拍和目标画面。

- 与白天日常状态复用同一套基础地图、玩家、小屋、树和作物资源。
- 首批只允许使用全局冷暗覆盖、雾/粒子、一个关键轮廓或边界替换、有限 UI 扰动和声音草案。
- 不复制整套地表，不制作屠村、神石愿望、战争残响真身或愿境揭露素材。
- `wechat-low` 关闭粒子或 Shader 后，仍通过色调、轮廓、声音和对白表达异常。

## 验证场景要求

首个小场景只需要：

- 一小块草地与泥土；
- 小屋；
- 一棵树；
- 雾叶草三个阶段；
- 玩家角色；
- 一条能够测试角色从树冠或屋檐后经过的路线；
- 白天、黄昏、夜晚、下雨四个可切换状态；
- 阶段 10D 确认后的日常/异常最小状态切换；
- `wechat-low` 与 `pc-high` 两种画质预设。

场景通过前不制作完整村庄，不批量生成十五名 NPC，也不制作完整家具、建筑、作物或特效库。

## 首个对话立绘试制包，视觉验证包通过后启动

### PORTRAIT-PILOT-001 核心角色立绘

状态：`[ ]`，阶段 10C 已选定 `npc_shen_he`（沈禾）并锁定内容简报；视觉验证包通过前不开始绘制。

| 项目 | 规格 |
| --- | --- |
| 角色数量 | 1 名核心角色：沈禾，`npc_shen_he` |
| 源文件 | 推荐 1024×1536，可编辑分层文件 |
| 运行时导出 | 首版 512×768 透明 PNG；微信内存不足时再评估 384×576 映射 |
| 常用状态 | `neutral`、`smile`、`happy`、`shy`、`angry`、`sad`、`surprised`、`thinking` |
| 姿势 | 先做默认姿势；只为试制对白实际需要补充 1～2 个姿势 |
| 服装 | `default` 1 套，不在试制包中扩张季节衣柜 |
| 效果 | 只为实际对白需要制作 `blush`、`tear`、`shadow_face` 等有限差分 |
| 方向 | 优先验证安全镜像；不对称设计才导出左右独立资源 |
| 一致性 | 发型、服装、配饰、年龄、体型和配色与 96×96 场景 Sprite 一致 |

角色识别与关系测试场景见 `docs/NPC_BIBLE.md`。建议运行时位置：`assets/art/portraits/npc_shen_he/`。

本清单只确认未来资源输入，不授权在当前主开发任务中生成立绘。实际制作时必须按 `docs/RESOURCE_CREATION_WORKFLOW.md` 另开任务，并回交源文件、导出图、状态表与来源记录。

验收：同一段测试对白能连续切换至少四种表情/姿势；当前说话者正常亮度、另一角色被统一 dim；切换无明显闪烁；精确资源缺失时按 `docs/DIALOGUE_SPEC.md` 回退且对白不中断；微信低档内存和 Draw Call 可接受。

### 批量生产门槛

只有阶段 10C 已锁定试制角色，且 PORTRAIT-PILOT-001 在 640×360、另一横屏尺寸、微信真机和 Windows 预览中通过后，才按角色重要度生产：

- 核心角色：至少八个常用状态；
- 普通 NPC：`neutral`、`happy`、`surprised`，以及 `angry` 或 `sad` 中至少一种；
- 十一名开场成年告白对象不会因此在 Demo 阶段自动批量生产资源；某条完整恋爱线获批进入制作时，该角色必须升级为至少八个常用状态的核心关系角色预算，并检查男性/女性主角形态所需的显式对白或动作差分；罗岑山与陈蕴只按非恋爱老年长辈预算制作；
- 乔苓与阿桃的成年版本不属于当前 Demo 资源包；完整产品允许时间推进到其 18 岁生日之前，必须在独立资源任务中交付成年场景 Sprite、成年立绘、称谓/对白状态表和年龄切换清单，儿童素材不得用于成年恋爱内容；
- 特殊剧情状态：只按已确认对白需求制作，不为所有字段组合批量出图；
- 每个角色必须同时交付像素 Sprite 对照、立绘状态清单、源文件、运行时导出和来源登记。
