# 《雾乡如昨》Demo 开场流程与三地图拓扑

## 文档地位

本文件是阶段 10B 的纸面流程与地图功能基线。它定义玩家从标题界面进入第一章、建立日常、遭遇第一处结界异常并返回自由生活的流程，以及三张玩法地图的职责、连接和灰盒预算。

本文件不决定正式地图美术、人物造型、音乐、环境声、音效或具体视听表现。相关资源的创作、选择与风格定稿必须在独立任务/对话中完成，再以稳定资源 ID 和表现接口回填当前项目。

## 已锁定的范围决定

- 当前 Demo 使用恰好三张玩法地图，不额外拆分农场、村庄、道路或教学房间。
- 标题、档位选择、设置、暂停和 Demo 达成提示属于应用 UI，不计入三张玩法地图。
- 三张地图使用稳定逻辑 ID：
  - `home_interior`：主角住宅室内；
  - `hometown_main`：故乡日常主区域；
  - `boundary_pass`：结界边界区域。
- 玩家可见地图名必须使用本地化键，不能直接显示逻辑 ID。
- 地图基础瓦片保持 `32×32`。阶段 11 可以依据灰盒试玩按 4 格倍数微调宽高，但不得改变三张地图的职责和连接关系。
- 技术 MVP 的室外休息点仅作为历史占位。Demo 中由住宅床铺承担睡觉与跨天交互。

## 总体连接拓扑

```text
标题 / 档位 UI
       |
       v
+-------------------+
| home_interior     |
| 醒来、首次对白、   |
| 基础提示、床铺     |
+---------+---------+
          | 住宅门（双向）
          v
+-------------------+
| hometown_main     |
| 农田、住宅外部、   |
| 村民、关系片段、   |
| 长期自由生活       |
+---------+---------+
          | 北侧山路（双向；流程解锁）
          v
+-------------------+
| boundary_pass     |
| 山路、边界、       |
| 第一处结界异常     |
+-------------------+
```

禁止建立 `home_interior -> boundary_pass` 的直接通道。玩家必须经过日常主区域，让住宅、村庄与边界形成可理解的地理关系。

## 灰盒尺寸预算

| 地图 ID | 初始灰盒尺寸 | 世界像素尺寸 | 主要原因 |
| --- | --- | --- | --- |
| `home_interior` | `20×12` 格 | `640×384` | 单层住宅可在 640×360 横屏中保持完整空间关系，又为墙体和家具碰撞留出余量 |
| `hometown_main` | `64×48` 格 | `2048×1536` | 同时容纳住宅外部、农田、村庄核心与通往边界的道路，不拆出第四张地图 |
| `boundary_pass` | `40×24` 格 | `1280×768` | 支持从安全入口逐步接近边界、触发异常并返回，避免做成长距离空路 |

这些尺寸是阶段 11 的首次灰盒输入，不是正式美术画布承诺。调整必须记录原因，并同时验证摄像机边界、低端设备节点数量和玩家步行时间。

## 地图一：`home_interior`

### 功能职责

- 第一章醒来与首次可操作状态；
- 村长对“昏倒后被送回家”的解释；
- 最小移动、交互与离开房屋提示；
- 床铺睡觉、跨天和日后读档安全落点；
- 为少量可检查物和后续住宅扩展保留空间，但不在 Demo 中建设完整家具系统。

### 功能平面草图

```text
北
+----------------------------------+
| 储物/预留        床铺 B            |
|                                  |
|            可移动区域              |
|                                  |
| 首次对白锚点 V    桌面/基础物品      |
|                                  |
|                         住宅门 D   |
+----------------------------------+
南
```

### 稳定锚点

| 锚点 | 用途 |
| --- | --- |
| `home_wake` | 新游戏第一章醒来位置；玩家默认朝向房间内部 |
| `home_bed` | 睡觉交互与跨天完成后的室内出生位置 |
| `home_door_inside` | 从日常主区域返回住宅后的入口 |
| `home_elder_opening` | 村长首次对白站位；对白完成后可退出或切换到后续日程锚点 |
| `home_starter_items` | 基础工具/种子的领取或说明位置；具体表现留待后续系统设计 |

### 规则

- 新游戏必须从 `home_wake` 开始，不能直接出生在农田。
- 首次对白前允许玩家在房间内移动和检查，但住宅门暂不完成场景切换。
- 首次对白完成后开放住宅门；以后返回住宅不重复完整开场。
- 床铺只在满足睡觉规则时推进日期。地图切换本身不推进日期。
- 室内不允许耕地、播种、浇水或触发边界异常。

## 地图二：`hometown_main`

### 功能职责

- 承载现有耕种闭环的正式 Demo 版本；
- 展示主角住宅外部、农田、村庄核心和主要村民存在；
- 承载至少一个关系玩法代表片段；
- 作为玩家长期自由生活的中心地图；
- 连接住宅与结界边界，使异常路线从可信日常中自然延伸。

### 功能平面草图

```text
北
                         山路出口 P -> boundary_pass
              +-------------------------------+
              | 村庄核心 / 公共活动区          |
              | NPC 锚点与关系片段             |
西            |                               | 东
+-------------+-------------------------------+
| 住宅外部 H  | 日常道路 / 少量检查点 / 预留区  |
| 农田 F      |                               |
| 教学农格 T  |                               |
+---------------------------------------------+
南
```

### 稳定功能区与锚点

| 标识 | 用途 |
| --- | --- |
| `main_home_door` | 与 `home_door_inside` 双向连接 |
| `main_safe_spawn` | 无法恢复原入口时的安全回退点，不用于正常新游戏 |
| `main_farm_plot` | 玩家长期耕种区；沿用耕地、播种、浇水、成长和收获规则 |
| `main_tutorial_plot` | 第一日教学使用的少量可耕格，属于农田的一部分 |
| `main_village_core` | 公共活动区与主要 NPC 锚点集合 |
| `main_relationship_beat` | 沈禾第一日关系预览事件位置；逻辑上对应 `main_npc_farm_edge` |
| `main_boundary_path` | 通往 `boundary_pass` 的入口；第一日流程完成前不触发地图切换 |

### NPC 容量规则

- 阶段 10C 已为五名幸存者和十名重构村民分配稳定默认锚点，完整表见 `docs/NPC_BIBLE.md`。
- 不要求十五人同时出现在同一屏幕，也不在阶段 10B 定义完整日程系统。
- 第一日只让少数角色承担引导和关系片段，避免把开场变成连续人物介绍。
- 不将 NPC 身份、职业或立绘状态写死在地图结构中；地图只提供逻辑锚点。
- `main_npc_*` 锚点只表示默认存在位置；未来日程变体不得改变稳定角色 ID，也不得成为 Demo 的前置依赖。

## 地图三：`boundary_pass`

### 功能职责

- 建立“这里原本是一条可以离开故乡的道路”；
- 在日常解释仍成立的前提下，让玩家亲自确认道路无法正常穿越；
- 承载第一处结界异常和一个可复查线索；
- 异常后允许玩家返回日常，不进入最终真相期，也不触发不可逆确认。

### 功能平面草图

```text
北
+------------------------------------------+
| 边界探测区 X / 不可正常穿越的出口          |
|                  线索检查点 C              |
|                                          |
|          接近路径与节奏缓冲区              |
|                                          |
| 安全返回锚点 R                            |
| 入口 S <- hometown_main                   |
+------------------------------------------+
南
```

### 稳定锚点

| 锚点 | 用途 |
| --- | --- |
| `boundary_entry` | 从日常主区域进入的位置 |
| `boundary_return` | 异常完成或穿越失败后的安全回退位置 |
| `boundary_probe` | 首次异常的单次触发区域 |
| `boundary_clue` | 异常前后状态不同、可重复检查但不泄露核心真相的线索点 |
| `boundary_exit_blocked` | 表示通向故乡之外的概念出口，不连接第四张地图 |
| `boundary_npc_watch` | 晏巡在边界相关事件中的受控站位 |
| `boundary_npc_stream` | 何舟可选环境观察事件站位；不作为异常前置 |

### 第一处异常的功能结果

阶段 10B 只锁定事件的可观察结果，不决定其美术、音乐或音效方案：

1. 玩家在第二日以后主动进入边界区域；
2. 玩家接近 `boundary_probe`，确认继续前进无法抵达故乡之外；
3. 一次短事件结束后，玩家位于 `boundary_return`，仍能自由移动；
4. `boundary_clue` 进入可检查状态；
5. 记录 `first_barrier_observed`，完整异常不再重复播放；
6. 玩家可以检查线索、返回村庄或继续普通日常；
7. 事件不揭露屠村、三个愿望、愿境或重构村民来源。

具体画面变化、声音、镜头语言、粒子和资源规格必须由独立视听资源任务决定。实现只消费该任务给出的表现配置，不把表现细节写进剧情状态机。

## 第一章纸面流程

### A. 标题与档位

1. 玩家从标题界面选择新游戏或已有档位；
2. 新游戏建立第一章初始状态并加载 `home_interior`；
3. 继续游戏恢复保存的地图与入口；若旧版本存档没有地图字段，迁移到 `home_bed`。

### B. 住宅醒来

1. 玩家在 `home_wake` 醒来；
2. 通过最小提示获得移动和交互能力；
3. 玩家与村长完成首次对白，得知自己昏倒后被人送回；
4. 玩家获得或确认基础工具与种子；
5. 住宅门开放，玩家可以进入日常主区域。

### C. 第一日日常建立

1. 玩家抵达住宅外部并认识农田位置；
2. 完成少量锄地、播种和浇水，不要求清空整块农田；
3. 与记忆中熟悉的少数村民重新碰面；对白面向玩家介绍人物，但主角不把他们当陌生人；
4. 完成一个代表性关系互动；
5. 返回住宅，在 `home_bed` 睡觉进入第二日。

### D. 第二日自由生活与边界开放

1. 玩家看到跨天后作物和农田状态变化；
2. 日常目标变为非强制建议，玩家可以继续耕种、交谈或前往北侧山路；
3. 当日期至少为第二日，且耕种引导与代表性关系互动已经完成时，设置 `world.boundaryRouteAvailable` 并开放 `main_boundary_path`；只开放地图入口，不自动把玩家传送到边界；
4. 玩家若不前往边界，可以持续普通日常，不会因日数自动触发异常。

### E. 可选的第一处异常

1. 玩家主动进入 `boundary_pass` 并接近边界；
2. 首次异常按“功能结果”执行并记录里程碑；
3. 玩家可检查线索或立即离开；
4. 返回日常主区域后显示非阻塞的 Demo 里程碑反馈；
5. 玩家可以继续当前存档的自由生活，Demo 不强制退回标题。

## 叙事与目标状态

阶段 12B 以版本化存档承载以下最小状态。名称是稳定语义建议，不要求阶段 10B 创建代码：

```text
opening.woke
opening.elderConversationCompleted
opening.leftHome
daily.farmingIntroCompleted
daily.relationshipPreviewCompleted
world.boundaryRouteAvailable
mystery.firstBarrierObserved
demo.milestoneReached
```

日期不能替代这些显式状态。日期可以参与开放条件，但不能单独触发第一处异常或最终真相线。

## 场景切换规则

- 所有切换通过命名入口完成，禁止业务逻辑散落硬编码世界坐标。
- 每个入口声明来源地图、目标地图、目标锚点和开放条件。
- 切换时先抑制世界输入，完成目标地图加载与玩家定位后再恢复输入。
- 切换失败时玩家留在来源地图，并得到可本地化的反馈；不能停在黑屏或未加载地图。
- 当前地图 ID、玩家位置/朝向和叙事状态必须进入 SaveData v2；阶段 9 的 v1 存档通过确定迁移落到 `home_bed`。
- 普通地图切换不推进日期，也不自动替代睡觉后保存。自动保存策略的扩展由阶段 10E 与 12B 决定。
- 读档时若目标入口无效，使用该地图的安全回退锚点并记录可诊断错误；不能猜测最近坐标。

## 关键边界场景

- 玩家首次对白前反复检查住宅门：不会离开房间，也不会重复创建村长对白。
- 玩家第一日提前走到山路：入口保持关闭，只给出日常层解释，不播放异常。
- 玩家第二日完全忽略山路：可以持续耕种和交谈，不自动推进悬疑。
- 玩家在边界地图退出并读档：恢复到已保存的地图/入口；旧存档按迁移规则落到住宅。
- 玩家触发异常后再次接近边界：只显示简短的已观察反馈，不重复完整事件。
- 玩家触发异常后继续睡觉多日：不会自动进入主动调查或最终真相期。
- 地图或入口配置缺失：加载明确失败并回退安全入口，不能把玩家放到 `(0, 0)`。

## 阶段 11 灰盒验收输入

- 三张地图均能独立加载并按拓扑双向切换；
- 住宅醒来、首次对白门禁、住宅床铺和离开住宅流程可走通；
- 日常主区域从住宅到农田、村庄核心和边界入口的步行路线可辨认；
- 边界入口关闭、开放、首次异常安全回退和重复接近四种状态可验证；
- 640×360 与另一横屏比例下摄像机不显示地图外区域；
- 地图切换期间输入不会串入下一地图；
- 不依赖正式美术、音乐或音效即可完成全部功能验收。
