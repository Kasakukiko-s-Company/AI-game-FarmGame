# 游戏设计草案

本文描述“做什么游戏”，不作为最终技术实现或数值表。以下产品基线已于 2026-07-13 确认。

## 基本定位

- 开发代号：《云岚药圃》（正式名称在发布前另行确定并检查重名/商标）
- 类型：原创 2D 像素风农场生活模拟
- 视角：俯视角
- 目标平台：微信小游戏与 Steam Windows 双平台；共享玩法保持一致，平台能力通过 adapter 隔离
- 画面方向：横屏，640×360 逻辑设计分辨率
- 推进方式：按游戏日推进，短时段可随时暂停
- 目标玩家：喜欢轻量种植、整理、成长反馈和东方幻想氛围的玩家

## 原创核心方向

玩家照料一座被山雾环绕的药草圃。不同药草与天气、晨露和地块状态产生关系；玩家通过恢复田地和培育药草，让原本沉寂的山谷逐步恢复生机。

与常见农场生活模拟游戏区分的长期方向：

- 主题聚焦东方幻想药草，而不是复刻既有商业游戏的角色、村镇或作物表。
- 农务决策围绕露水、土壤和药性，不复制其他游戏的具体数值与配方。
- 山谷变化由玩家的生态选择驱动，而不仅是线性扩建。
- 长期可探索药草杂交、药膳/茶饮和生态修复，但均不属于 MVP。

## 核心循环

完整产品的候选循环：

> 规划地块 → 种植与照料 → 收获 → 加工或交付 → 改善药圃 → 解锁新品种和区域

MVP 只验证：

> 移动 → 锄地 → 播种 → 浇水 → 睡觉 → 成长 → 收获 → 保存与恢复

MVP 不实现出售、加工、升级或解锁，避免在种植闭环跑通前扩张经济系统。

## 世界与地图

MVP 仅有一张使用 32×32 像素瓦片的 30×30 药圃地图：

- 一块 10×10 可耕作区域
- 一间不可进入、只作为背景的木屋
- 一个位于屋外的睡觉交互点
- 不可行走的边界和少量环境阻挡

长期候选区域包括山麓、溪谷、竹林和小镇，但不在 MVP 内承诺。

## 时间与成长

- 游戏按天结算作物成长。
- 玩家主动在睡觉交互点结束当天。
- MVP 不设计体力值、天气随机、季节限制或失败惩罚。
- 作物只有在当天浇水后才成长；未浇水则停止成长，但不会枯死。

## 物品与经济

MVP 物品只有锄头、水壶、雾叶草种子和雾叶草收获物。

货币、商店、售价、加工和升级属于后续设计。数据结构可以预留价格字段，但 MVP 不因此实现交易系统。

## 操作

- PC：WASD/方向键移动，快捷键或按钮选择工具，交互键执行动作。
- 微信：横屏双手操作，左侧虚拟摇杆，右侧独立动作按钮，快捷栏位于不遮挡主要视野的位置。
- 两端共享同一组“移动、选择、交互、取消”语义，不让玩法依赖具体按键。

## 美术与声音

- 像素风、清晰轮廓、有限色板、柔和东方幻想氛围。
- MVP 可使用项目内原创几何占位资源，不使用任何商业游戏素材。
- 字体、音乐、音效和图像均须有来源与许可证记录。

## NPC 与叙事

MVP 不包含 NPC、对白、任务和剧情。

长期叙事如继续设计，应围绕原创山谷、药圃与生态修复展开，所有角色、文本和事件独立创作。

## 已确认的 MVP 约束

- 《云岚药圃》和雾叶草是开发代号与占位内容，允许在不改变代码 ID 的前提下更换显示名称和美术。
- 使用横屏、640×360 逻辑设计分辨率和 32×32 像素瓦片。
- 使用一个自动存档槽。
- 不加入货币、出售、商店或加工。
- 房屋不可进入；未浇水只停止成长，不产生枯死惩罚。
