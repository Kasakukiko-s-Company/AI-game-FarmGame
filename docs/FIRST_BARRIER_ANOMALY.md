# 《雾乡如昨》第一处结界异常规格

## 文档地位

本文件是阶段 10D 的权威事件规格，定义 Demo 在 `boundary_pass` 中首次确认结界异常的触发、节拍、对白、线索、恢复、双状态构图与资源接口。阶段 11 的灰盒和双状态视觉样片、阶段 15 的运行时实现都必须以本文件为输入。

本阶段只编写功能与资源简报，不生成美术、音乐、环境声或音效，也不修改现有玩法代码。正式视听资源的创作、候选比较与定稿必须按 `docs/RESOURCE_CREATION_WORKFLOW.md` 在独立任务/对话中完成。

本文件包含内部叙事意图，但事件本身必须遵守 Demo 保密边界。

## 已锁定结论

- 内部事件 ID：`anomaly.first_barrier_fold`。
- 内部工作名：**界碑回折**。玩家界面只使用“山路异象”“北侧山路”一类日常词汇，不显示“结界”“愿境”或内部事件 ID。
- 事件位于 `boundary_pass` 北侧概念出口前，不增加第四张地图。
- 玩家必须主动走到旧界碑处并提交一次“继续沿旧山路往前”的语义交互；进入地图、日期变化、好感变化和普通睡觉都不会自动触发。
- 异常的核心可观察结果是：玩家没有回头，却再次看见刚经过的旧界碑，并被道路安全送回南侧。
- 事件结束后出现一条可选线索：原本系在界碑上的褪色路标布出现在返回点附近，布结仍完整。
- 晏巡承担事件后的克制回应，但她的好感、关系状态和事前对话不是触发条件。
- 玩家可以不检查线索、立即返回日常，并在此后无限期继续耕种与交友；本事件不进入主动调查期或最终真相期。
- 不出现怪物、尸体、鲜血、军队、神石、愿望画面、战争残响真身或突然贴脸惊吓。

## 体验目标

本事件要在一次短而可控的微恐体验中同时完成四件事：

1. 让玩家亲自确认“这条原本能离开故乡的路现在无法正常穿越”；
2. 让玩家怀疑空间、记忆或村民解释中的至少一项不可靠；
3. 通过晏巡过于克制的反应暗示“有人知道得更多”，但不证明幸存者集体隐瞒；
4. 明确把控制权还给玩家，让不想调查的人可以回到稳定日常。

事件不是惩罚、追逐或不可逆选择。玩家感受应从“熟悉山路上的轻微不对劲”上升到“短暂确认异常”，随后回落到仍能生活的余悸，而不是立刻进入恐怖游戏常驻状态。

## 空间位置与锚点

阶段 11 可以调整 `boundary_pass` 的具体格坐标，但必须保留以下相对关系：

```text
北 / 故乡之外
+------------------------------------------+
| boundary_exit_blocked：看似可通行的山口 B |
|              旧界碑 M + 初始路标布 R0     |
|              boundary_probe P            |
|                                          |
|        6～8 格节奏缓冲与回折展示区        |
| boundary_npc_watch W    boundary_clue C  |
| boundary_return R                        |
| boundary_entry S <- hometown_main        |
+------------------------------------------+
南 / 故乡内部
```

| 锚点/对象 | 相对位置与规则 |
| --- | --- |
| `boundary_exit_blocked` | 地图北缘中央的概念出口；正常态看起来仍有道路延伸，但永远不连接第四张地图 |
| `boundary_marker` | 位于出口南侧约 2 格、主路一侧的旧界碑；必须在 640×360 中有清楚轮廓 |
| `boundary_probe` | 位于旧界碑南侧或同排、覆盖主路宽度；玩家面向北并主动交互才触发 |
| `boundary_return` | 位于探测区南侧 6～8 格，且完整落在摄像机与碰撞安全区内 |
| `boundary_clue` | 返回点右前方 1～2 格；异常前不可交互，异常后显示“返回的路标布” |
| `boundary_npc_watch` | 返回点左前方 2～4 格；用于晏巡受控事件实例，不阻挡返乡路径 |
| `boundary_entry` | 地图南侧入口；从进入点到探测区至少保留一屏以内的正常步行缓冲 |

旧界碑、路标布和出口必须全部属于表现/交互对象，不得把核心判断建立在玩家不可见的硬编码世界坐标上。

## 前置日常与开放条件

`world.boundaryRouteAvailable` 仍按阶段 10B 的开场流程开放：

- 已完成住宅醒来与村长首次对白；
- 已完成第一日少量耕种引导；
- 已完成一次代表性关系互动；
- 已至少睡过一次，当前世界日期不早于第二日。

这些条件只开放从 `hometown_main` 前往 `boundary_pass` 的道路，不触发异常。代表性关系互动是固定开场节点，不读取好感数值，也不要求玩家选择特定暧昧、友谊或对白结果。

第一处异常还必须同时满足：

```text
world.boundaryRouteAvailable == true
mystery.firstBarrierObserved == false
player is inside boundary_probe
player is facing the conceptual exit
player submitted semantic interact/confirm once
```

以下行为都不能触发完整异常：

- 日期增加、作物成熟、睡觉或自动保存；
- 仅进入 `boundary_pass`；
- 仅接近旧界碑但没有交互；
- 与晏巡、何舟或任意 NPC 对话；
- 好感达到阈值、告白、恋爱或结婚；
- 点击地图其他位置、切换画质或恢复前后台。

## 主动触发反馈

玩家进入 `boundary_probe` 且面向北时，显示普通交互提示：

```text
继续沿旧山路往前
```

它使用正常“检查/继续”语义，不使用危险红色确认框，也不伪装成未来的“不可逆调查”确认。玩家可以转身、离开或取消，不产生状态变化。

提交交互后才短暂抑制移动、工具、快捷栏、地图切换和暂停之外的世界操作。无障碍设置允许关闭镜头移动、粒子与轻微画面偏移，但不能跳过最终状态、对白和安全回退。

## 首次异常节拍

整段无对白表现建议控制在 `6～10` 秒，随后进入简短晏巡对白。具体过渡时长可在阶段 15 调整，但不得改变事件顺序。

| 节拍 | 画面/操作 | 声音语义 | 状态 |
| --- | --- | --- | --- |
| 0. 正常接近 | 日常色调、道路通向北侧亮部，旧界碑在道路一侧 | 正常山风、虫鸟或溪流环境声 | 玩家自由控制 |
| 1. 主动越界 | 玩家确认后向北走 1～2 个短步；镜头只做轻微前移或保持固定 | 日常环境声在约 0.5 秒内抽离，不能用爆音 | 输入暂时抑制，尚未提交持久状态 |
| 2. 道路回折 | 玩家刚越过界碑，同一界碑轮廓却再次出现在前方；道路没有明显转弯 | 远处脚步与玩家最后一步形成一次错位回声 | 不显示怪物或实体墙 |
| 3. 空间收紧 | 冷暗低饱和覆盖进入，薄雾从道路两侧向中线收拢；出口仍看得见但距离不再缩短 | 低频空气感或窄带环境层进入；必须可被关闭 | 不闪屏、不剧烈抖动、不快速旋转 |
| 4. 安全回折 | 画面进行一次短遮蔽/构图切换，玩家落在 `boundary_return`，面向北；旧界碑回到正常位置 | 一次克制的落步/布料声确认位置变化 | 设置 `mystery.firstBarrierObserved=true`，清理瞬态表现 |
| 5. 余悸与对白 | 日常亮度在约 1 秒内恢复；`boundary_clue` 出现路标布，晏巡位于 `boundary_npc_watch` | 正常环境声恢复，但可以保留短暂稀疏感 | 进入简短对白，结束后恢复全部控制 |
| 6. 返回自由生活 | 玩家可检查线索、再次靠近山口或立即返村 | 回到正常地图音频状态 | 设置 `demo.milestoneReached=true`，不切换叙事阶段 |

“道路回折”不能表现成普通碰撞墙：玩家必须看到自己已经越过旧界碑，而后界碑又在前方出现。即使关闭全部粒子和 Shader，也要通过旧界碑位置变化、玩家安全回位、字幕/旁白和交互结果表达异常。

## 线索状态与忽略行为

### 返回的路标布

- 异常前：路标布以 `prop.boundary.trail_ribbon.tied` 状态系在旧界碑上，不可单独拾取。
- 异常后：界碑上的布消失，`boundary_clue` 显示 `prop.boundary.trail_ribbon.returned`。
- 玩家检查后只记录线索已读，不把布加入背包，避免本阶段引入任务物品系统。
- 线索同时允许“风、旧绳、记忆偏差或有人移动过”等日常解释；它不能单独证明空间重构或愿境。

### 玩家忽略线索

- `mystery.firstBarrierObserved` 与 Demo 里程碑仍成立；
- 路标布保留在 `boundary_clue`，以后返回仍可检查；
- 当前目标只给一次非阻塞提示，不持续闪烁、不阻止睡觉、不阻止关系或耕种；
- 日数、好感和反复进入地图都不会替玩家自动检查；
- 忽略线索不会错过 Demo 的自由生活，也不会触发惩罚或坏结局。

## 重复接近与后续状态

首次事件完成后再次进入 `boundary_probe`：

- 不重播完整道路回折和晏巡对白；
- 玩家在旧界碑前得到一次短反馈，例如本地化键 `feedback.boundary.path_does_not_close_distance`；
- 表现为走近 1 步后仍停在原处或被柔和推回，不使用伤害、眩晕或长时间输入锁定；
- 玩家仍能自由返回村庄；
- 即使连续睡过多日，也不自动升级为更强异常、怪物出现或不可逆调查。

后续主动调查内容必须使用新的显式状态与玩家选择，不得把 `mystery.firstBarrierObserved` 当成进入最终真相期的充分条件。

## 运行状态与安全恢复契约

### 持久状态

```text
world.boundaryRouteAvailable
mystery.firstBarrierObserved
mystery.boundaryRibbonInspected
demo.milestoneReached
```

### 瞬态表现状态

```text
idle -> armed -> presenting -> recovered -> idle
```

`armed` 与 `presenting` 只属于当前场景会话，禁止写入存档。持久状态只在玩家已经安全落到 `boundary_return`、瞬态效果能够清理时提交。

必须满足：

- 事件开始时记录 `boundary_return` 作为本次安全回退，不复制或覆盖未来“调查前恢复点”；
- 演出期间拒绝重复输入、工具动作和地图切换；暂停/前后台恢复后只继续一个事件实例；
- 若演出在持久提交前被中断，读档后可以从上次稳定存档重新触发；
- 若 `mystery.firstBarrierObserved=true`，读档不得重播完整首次事件；角色若落在无效坐标，回退到 `boundary_return`；
- 清理时恢复摄像机、颜色覆盖、环境声、输入上下文和 NPC 控制权；任何一项资源缺失都不能让玩家被永久锁住；
- 阶段 10E 决定自动保存时机。本阶段不把普通异常观察伪装成最终真相期的受保护恢复点。

## 双状态目标构图简报

两张目标图必须使用相同的 `16:9` 机位、基础道路、旧界碑、植被和玩家位置范围，让评审能直接比较“同一地点从日常渗漏到异常”，而不是误以为更换了地图。

### A. 日常目标图：`visual_target.boundary_day_normal`

- 机位：640×360 横屏；玩家位于画面下方约 40% 高度、道路中线略偏左，朝向北。
- 构图：道路从下方形成轻微 S 形，引向上方中央偏亮的山口；旧界碑位于右上三分线，轮廓清楚但不是恐怖物件。
- 空间：道路两侧保留正常草木与低密度雾，远处仍有可通行的视觉邀请，不出现发光墙或黑色裂缝。
- 角色：晏巡可位于左侧中景，保持日常巡山姿态；目标图也必须在隐藏晏巡后仍成立。
- 色调：延续白天自然绿、暖灰石材和低饱和靛青路标布；不提前使用强烈冷紫或大面积压黑。
- 视觉焦点顺序：山口 → 玩家 → 旧界碑/路标布。
- 手机可读性：旧界碑和路标布在等比缩小后仍靠轮廓与明度差可辨，不只靠颜色。

### B. 异常目标图：`visual_target.boundary_first_fold`

- 机位：与日常图相同，不旋转镜头、不使用鱼眼和大幅倾斜。
- 核心错位：玩家已经越过旧界碑，但画面前方再次出现同一界碑轮廓；原先开阔的山口距离感被薄雾压平。
- 覆盖：使用可关闭的冷暗低饱和全局覆盖，画面仍保留路径、玩家和返回方向；黑位不得吞掉像素轮廓。
- 雾：从道路两侧向中线缓慢收拢，数量少、速度低；关闭粒子后改用两到三层静态/帧动画雾带。
- 关键替换：只替换/移动旧界碑与路标布状态，不复制整套地表、树木或建筑。
- UI：可以短暂降低普通 HUD 装饰存在感，但快捷栏、字幕和退出/暂停语义必须可读；不使用故障弹窗伪装游戏错误。
- 视觉焦点顺序：重复出现的旧界碑 → 玩家 → 被压平的山口。
- 禁止：贴脸人影、血字、尸体、军队剪影、神石图案、重构村民闪现、大面积屏幕撕裂或高频闪烁。

| `sfx.boundary.fold_step` | 错位脚步/落步确认 | 以字幕和画面错位替代 |
| `sfx.boundary.ribbon_drop` | 路标布落到返回点的克制布料声 | 静默，不影响线索出现 |

第一版不要求专属完整异常音乐。若需要音乐变化，只允许对当前日常音乐做短暂降层/停顿或在独立音频任务中制作一个可无缝退出的短层，不得让缺少音乐阻塞事件。

## Demo 保密检查

本事件可以让玩家推测：

- 山路空间异常或总会把人送回；
- 晏巡可能以前见过类似情况；
- 村庄对外交通并不像日常解释那样简单；
- 路标布的位置与记忆不一致。

本事件不得直接证实：

- 故乡是愿境或模拟世界；
- 结界来自主角的第二个愿望；
- 村庄曾遭军队屠杀；
- 战争残响的来源；
- 五名幸存者的共同隐瞒；
- 任意村民是由死者记忆重构的新生命；
- 神石拥有三个愿望或主角已经使用愿望；
- 调查已经不可逆。

任何新增台词、图案、音效人声或视觉剪影都必须重新经过本清单检查。资源创作任务不得擅自加入“更吓人但会泄底”的内容。

## 阶段 11 灰盒验收

- 在无正式美术、无音频情况下，玩家仍能通过旧界碑回折、返回点和文字反馈理解异常。
- 玩家只有在 `boundary_probe` 主动交互后才触发；进入地图、睡觉和好感变化均不触发。
- 取消交互或转身离开不会写入任何异常状态。
- 首次事件只播放一次；重复接近得到短反馈并始终可返村。
- 路标布可以忽略、稍后检查，忽略不会阻塞日常或产生惩罚。
- 中断、资源缺失和场景加载失败都不会永久锁住输入或把玩家放到地图外。
- 日常态和异常态复用同一地图、机位与基础资源；关闭粒子、Shader、镜头移动和音频后功能仍成立。
- 晏巡对白不读取好感或恋爱状态，不泄露核心真相。
- 640×360 与另一横屏比例下，旧界碑、玩家、返回路径、字幕和交互提示都位于安全可读区域。

## 阶段 15 实现验收

- 叙事状态、瞬态表现状态、输入抑制与场景表现彼此分离，可独立测试。
- 事件不会因帧率、画质档、音频开关或 `reduceMotion` 得到不同叙事结果。
- `mystery.firstBarrierObserved` 不是主动调查期或最终真相期的自动入口。
- 事件完成后玩家可以继续耕种、关系互动、睡觉、存档、读档与地图切换。
- Demo 结束反馈是非阻塞里程碑，不强制回标题，也不销毁当前存档。
