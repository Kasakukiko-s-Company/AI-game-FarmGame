# Legal and IP Guidelines

本文件是项目工作规则，不构成法律意见。发布前如有不确定许可，应向合格专业人士确认。

## 原创要求

禁止复制、反编译、提取、描摹或改编：

- 《星露谷物语》或其他商业游戏的源代码与反编译代码。
- 商业游戏的美术、图块、地图、UI、字体、音乐和音效。
- 商业游戏的角色、对白、剧情、任务、名称和具体数值表。
- 盗版目录、解包资源和来源不明素材包。

通用类型与机制可以研究，但代码实现、数据、命名、内容、视觉和声音必须独立完成。

## 可接受来源

- 团队自行创作并保留源文件和创作记录的资源。
- 明确书面授权用于本项目和目标平台的委托作品。
- 经逐项审核、与商业发行兼容的开源或公共领域资源。
- 有购买凭证并允许游戏发行、修改和目标平台再分发的商业素材。

“可免费下载”“网上找到”或“AI 生成”本身不等于可安全使用。

## 资源登记

每个外部资源至少记录：

| 字段 | 说明 |
| --- | --- |
| Asset ID | 项目内稳定标识 |
| File paths | 使用位置 |
| Author/source | 作者与原始页面 |
| License | 许可证名称和版本 |
| Proof | 许可证快照、订单或授权文件位置 |
| Modifications | 裁剪、调色、混音等修改 |
| Attribution | 是否需要署名及准确文本 |
| Reviewed by/date | 审核人与日期 |

没有登记的外部资源不得进入发布构建。

## Code and Dependencies

- 每个第三方包记录名称、版本、来源和许可证。
- 不引入来源不明的代码片段或反编译实现。
- 引擎、插件、字体、音频和工具的许可证分别审核。
- 锁定依赖版本并保留许可证通知。

## References

参考截图只用于讨论抽象目标，例如层级、可读性或氛围，不作为描摹底稿。用户放入 `references/` 的内容也必须注明来源和用途。

允许优先放入：

- 用户自己的草图、设定图和地图草案。
- 已授权资源及其许可证。
- 官方技术文档摘记与链接。
- 对通用机制的文字观察，不包含受保护文本或具体复制数据。

## AI-assisted Content

如使用生成式工具：

- 记录工具、模型/版本（如可得）、日期、提示词摘要和输入参考来源。
- 不以上传未获授权商业素材的方式要求模仿。
- 人工检查与已有角色、图标、地图或音乐的实质相似性。
- 确认工具条款允许目标商业用途和再分发。

## Release Gate

发布前完成：

- 代码依赖许可证清单。
- 美术、字体、音乐、音效资源台账。
- 必要署名页面和第三方通知。
- 商标、游戏名称和商店素材复核。
- 微信平台隐私、数据与内容合规复核。
- 删除所有无授权占位资源和来源不明文件。
