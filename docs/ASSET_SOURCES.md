# Asset Sources

本文件记录项目运行时素材的来源和生成方式。未列入本文件或没有明确许可证的外部素材不得进入项目。

## 阶段 6C：雾叶草幼苗占位视觉

- 类型：原创运行时像素几何，不生成或引用外部图片文件。
- 创建日期：2026-07-15。
- 创建方式：`assets/scripts/farming/CropView.ts` 使用 Cocos `Graphics` 整数矩形绘制阴影、深绿茎、雾绿色双叶、浅色高光和后续阶段芽苞。
- 色板：阴影 RGBA `(71,55,39,150)`、茎 `(46,105,70,255)`、叶 `(61,137,88,255)`、高光 `(113,185,126,255)`、芽苞 `(174,211,151,255)`。
- 来源：项目内原创设计；未使用第三方图片、商业游戏资源、临摹素材或 AI 图片生成。
- 用途：阶段 6C～7 的可替换 MVP 作物状态占位表现，不是最终正式美术。

### `assets/maps/mvp_farm.tmx`

- 类型：原创最小测试地图。
- 创建日期：2026-07-14。
- 创建方式：生成器先在被 Git 忽略的 `temp/stage3-tiled` 中创建 Tiled JSON 源文件，再由本机 Tiled 1.12.2 使用 `--export-map tmx` 导出。
- 结构：正交、`30×30`、`32×32` 瓦片、`Ground`/`Obstacles`/隐藏 `Blocking` 图层、未压缩 CSV、嵌入 tileset。
- 用途：阶段 3A 验证导入显示；阶段 3B 使用出生点右侧 4 格石墙验证阻挡查询与角色碰撞。房屋、可耕作区和睡觉点尚未添加。
