# References

此目录仅放置用户自制、已获授权或许可证明确的参考资料。

建议分类：

- `screenshots/`：用户自己的 UI、布局或风格草图。
- `concept-art/`：用户自制或委托授权的角色、作物和建筑设定。
- `notes/`：玩法观察、操作方案、原创点子和官方文档摘记。

当前官方工具安装来源记录：[tool-installation-sources.md](notes/tool-installation-sources.md)。

每个外部文件旁应注明原始来源、作者、许可证和允许用途。不得放入商业游戏解包资源、反编译项目、盗版目录、原游戏音乐/地图或来源不明素材包。
