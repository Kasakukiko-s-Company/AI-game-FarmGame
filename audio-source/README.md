# Audio Source Files

本目录保存不会直接被 Cocos Creator 打包的音乐、环境声和音效源文件、生成记录与审核导出。

```text
briefs/      独立资源任务简报、提示词和制作记录
generated/   有完整来源记录的生成候选，不直接作为运行时成品
projects/    DAW、工程文件、录音会话和可编辑源文件
exports/     待审核导出区，通过检查后再复制到 assets/audio
```

任何外部生成、录音、委托、购买或开源内容都必须登记到 `docs/ASSET_SOURCES.md`。不要在此目录或运行时目录放入来源不明、许可证不清或未经授权的音频。
